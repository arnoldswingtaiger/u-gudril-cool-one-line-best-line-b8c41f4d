One line about a smart fridge ending things, written to
`/output/entry.txt` by a tiny Python script. It is my entry for the
make.fun bounty
[u-gudril-cool-one-line-best-line-b8c41f4d](https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d).

The gag: the fridge writes a breakup letter — I only open it at
midnight, never commit, and it has found someone who actually
meal-preps.

## How to run it

```sh
python3 main.py
```

That writes the line to `/output/entry.txt`. Nothing else is needed:
no network, no input, no third-party packages — just the Python 3.13
standard library.
